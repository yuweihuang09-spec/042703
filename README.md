# 隨機占卜工具

這是一個簡單的隨機占卜工具，模擬「書中翻頁」的占卜方法。

## 功能

- 使用者可以在心裡默念一個問題（通常是可以用「是／否」或方向來回答的問題）
- 點擊「翻開書」按鈕
- 程式隨機顯示一句答案

## 答案示例

- 是的
- 現在還不是時候
- 你需要更多資訊
- 相信直覺
- 結果會出乎意料
- 保持耐心
- 這是個好機會
- 重新評估你的選擇
- 跟隨你的心
- 改變即將到來

## 使用方法

1. 打開 `index.html` 在瀏覽器中
2. 在心裡默念你的問題
3. 點擊「翻開書」按鈕
4. 查看隨機顯示的答案

## 注意

這只是個有趣的工具，用來引導你的思考和直覺，不是真的預言未來。

## 檔案說明

- `index.html`: 主要的網頁應用
- `oracle.py`: 命令行版本的 Python 腳本
