# 108課綱高中國文字音字形學習平台

這是一個專為台灣高中生打造的互動式國文學習網站，結合字音練習、字形練習、易混淆字整理、成語講解、AI 錯題分析與學測模擬。

## 已實作功能

- 字音練習：題目顯示國字，學生輸入注音並即時判斷正確與否
- 字形練習：依讀音與提示選出正確字形，支援易混淆字比較
- AI 錯題分析：記錄錯題、分析弱點、推薦複習內容、顯示熟練度
- 遊戲化功能：XP、等級、每日簽到、連續 streak、徽章成就、排行榜
- 學測模擬：限時測驗、隨機題庫、自動計分、錯題解析
- 注音鍵盤：台灣注音按鍵介面，可點擊輸入並支援鍵盤快捷鍵
- AI 國文老師：解釋詞語、記憶法與聯想技巧

## 使用方式

1. 打開 `index.html` 在瀏覽器中
2. 點選「開始學習」或「今日挑戰」
3. 使用字音練習、字形練習、學測模擬以及 AI 教學助手
4. 持續練習即可累積 XP 與等級，並查看錯題分析

## 檔案說明

- `index.html`: 主要前端網頁應用，包含 HTML、CSS、JavaScript

## 開發備註

- 網頁採用現代卡片式設計、柔和漸層、圓角風格
- 強化手機與平板響應式體驗
- 提供互動動畫、答對音效、錯誤震動效果、學習熱力圖
- 此版本為前端展示版，可進一步接後端儲存進度與題庫資料
